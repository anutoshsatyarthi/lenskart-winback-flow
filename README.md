# Lenskart win-back — WhatsApp flow

An interactive prototype of a two-way WhatsApp conversation that restarts after a
store visit ended without a purchase.

**Live:** https://anutoshsatyarthi.github.io/lenskart-winback-flow/

Three customer personas, each opening on a different drop-off reason:

| Persona | Drop-off | Voice |
| --- | --- | --- |
| Aanya, 23 | Didn't like the collection | Fast, lowercase, trend-led |
| Rohan, 34 | Price was high + staff unavailable | Crisp, value-first, transparent pricing |
| Mrs. Sharma, 61 | Repair request unresolved | Warm, unhurried, plain language |

Each thread covers the same beats — drop-off, occasion, budget, frame shape,
colour, reference upload, selfie try-on, recommendations, free text, close — with
the copy rewritten per segment. Product cards carry in-thread Add to cart and
Wishlist actions.

Tap the replies to play it, or hit **Auto-play** to watch a full run.

Single static file, no build step, no dependencies.

Personas, stores and order histories are illustrative test data.
